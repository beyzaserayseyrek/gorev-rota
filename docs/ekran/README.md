# Ekran görüntüleri

Sunumda kullanılacak görüntüler bu klasöre aşağıdaki adlarla konur.
Mac'te ekran görüntüsü: **⌘ + Shift + 4**, sonra alanı seçin (dosya masaüstüne kaydedilir).

| Dosya adı | Ne görünmeli? | Durum |
|---|---|---|
| `test_ciktisi.txt` | `luajit tests/hepsi.lua` çıktısı (86 test geçiyor) | var |
| `01_testler.png` | Terminal'de `luajit tests/hepsi.lua` çıktısının sonu | alınacak |
| `02_java_karsilastirma.png` | `sh tests/java_karsilastir.sh` çıktısı ("aynı") | alınacak |
| `03_addons_listesi.png` | Karakter ekranında AddOns listesinde GörevRota | oyunda alınacak |
| `04_dump.png` | `/dump C_QuestLog.GetQuestsOnMap(...)` çıktısı | oyunda alınacak |
| `05_panel.png` | `/gr plan` sonrası oklarla sıralı panel | oyunda alınacak |
| `06_yon_oku.png` | Sıradaki durağı gösteren yön oku | oyunda alınacak |
| `07_liste.png` | `/gr list` çıktısı sohbet penceresinde | oyunda alınacak |
| `08_guncelleme.png` | Görev alındıktan/bittikten sonra kendiliğinden güncellenen panel | oyunda alınacak |
